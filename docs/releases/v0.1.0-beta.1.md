# PennCraft 0.1.0-beta.1

The first public PennCraft beta for Windows 11 x64.

## Downloads

- **PennCraft-0.1.0-beta.1-win-x64-setup.exe** — per-user installer, without administrator installation.
- **PennCraft-0.1.0-beta.1-win-x64-portable.zip** — extract the full folder and run PennCraft.exe.
- **SHA256SUMS.txt** — SHA-256 hashes for packages and build metadata.
- **BUILDINFO.json** — source commit, SDK and bundled runtime versions.

Both packages include .NET and are unsigned. Windows may show a publisher/reputation warning. Download from this repository's release page and compare the checksum. Follow your organization's software policy.

## Included

Desktop Pens and live Folder Portals; physical transfers with recovery records; native Windows item menus; screen-grid drag/resize; automatic arrangement; fold/unfold; saved item sizes; named layouts with restore and Undo.

This beta adds a dedicated app/tray icon, version/About information, opt-in first-run organization, unexpected-error logging and verified installer/portable packaging.

## Before testing

Back up your desktop and existing PennCraft data. Organization and transfers move real files. First launch offers an empty workspace instead. Keep the hidden .PennCraft desktop storage and %LOCALAPPDATA%\PennCraft settings together when backing up.

Uninstall retains settings and managed files. Exit before updating or uninstalling; the installer asks you to close a running instance.

## Known limitations

Shell placement, Win+D, Explorer restarts, virtual desktops, mixed-DPI screens and third-party providers need broad manual testing. Saved layouts require matching monitor/work-area/scaling configuration. Tabs, multi-selection, workspace pages, monitor profiles and automatic updates remain deferred. ARM64 and Windows 10 are not validated.

CI tests bundled-runtime startup, temporary saved-layout restoration, portable extraction, install, reinstall and settings-preserving uninstall on Windows Server 2025 runners. Those checks do not establish full Windows 11 desktop compatibility.
