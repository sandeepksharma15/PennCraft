# Security and privacy

Only the newest beta is maintained during early development. Release assets are unsigned until a signing process is introduced. Verify official downloads and checksums; a checksum is not a signature.

Do not publish private files, credentials, complete settings catalogs or personal paths in reports. Logs may contain paths and exception details. PennCraft has no built-in telemetry or silent update downloads.

For a suspected vulnerability, use private vulnerability reporting in the repository's Security tab if available. Otherwise open a minimal issue requesting a private contact channel without exploit details or sensitive data.

Runtime security fixes require rebuilt self-contained releases. Maintainers must review .NET updates and package advisories before releases.
